# Kotlin Unit Converter

A small command-line unit converter I built as a freshman in college while learning Kotlin.

## Features

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Kilometers to miles
- Miles to kilometers

## Run the program

Make sure Kotlin is installed, then run:

```bash
kotlinc Conversion.kt -include-runtime -d Conversion.jar
java -jar Conversion.jar
```

Follow the prompts in the terminal and enter the number for the conversion you want.

## What I practiced

- Kotlin variables and conditional logic
- Reading user input from the command line
- Converting and validating numeric values
- Building a simple interactive program
